# تحديث: الأسماء الإنجليزية + اسم المدرّس الظاهر + إدارة المالك + صلاحيات الفريق

## التركيب
1. انسخ الملفات فوق جذر المشروع بنفس المسارات.
2. شغّل:  python manage.py migrate      (الترحيل accounts/0004: أربعة حقول جديدة فقط)
3. لا مكتبات جديدة.

## ما الجديد
- **الأسماء بالإنجليزية (افتراضي):** عند تسجيل طالب باسم عربي يُحفظ ويُعرض اسمه بالإنجليزية (Ahmed Mohamed Ali) ويُحفظ الأصل العربي في `name_ar` ويظهر في صفحة الطالب بلوحة المالك. يمكن إيقافه من «إعدادات المنصة». الأسماء الحالية لا تتغير؛ لتحويلها: `python manage.py convert_names_en` (معاينة) ثم `--apply`.
- **اسم المدرّس الظاهر:** حقل «الاسم الظاهر للطلاب» في تعديل المدرّس (للمالك/من يملك قسم المدرّسين). فارغ = الاسم الكامل، أو اكتب مثلًا `M`. يظهر للطلاب والزوّار والإشعارات والمساعد الذكي؛ لوحة المالك ولوحة المدرّس تعرضان الاسم الحقيقي دائمًا.
- **الدخول لحساب المدرّس:** زر «إدارة حساب المدرّس من الداخل» في صفحة المدرّس. أُصلح خلل كان يُضيّع زر «العودة لحسابي» بعد الدخول.
- **كلمة مرور الطالب:** لا يمكن عرض الكلمة الحالية (مشفّرة). أُضيف زر «توليد كلمة مرور مؤقتة» تظهر مرة واحدة فقط، إضافة إلى التعيين اليدوي، ويُفكّ إيقاف الدخول المؤقت بعد المحاولات الخاطئة.
- **صلاحيات الفريق:** لوحة المالك ← «صلاحيات الفريق» (/owner/staff-permissions/): مصفوفة أدوار × صلاحيات. الافتراضي = السلوك القديم تمامًا.
