# منصة مدرستك — Madrastak Platform

منصة تعليمية متعددة المدرّسين مبنية بـ Django (بدون استخدام Django Admin — كل اللوحات مبنية من الصفر).

## التشغيل محليًا

```bash
python3 -m venv venv
source venv/bin/activate          # على ويندوز: venv\Scripts\activate
pip install "django>=5.0,<5.3" pillow
pip install pdfplumber pytesseract pdf2image        # مطلوبة لميزة "استيراد الاختبارات"
# على الخادم (Ubuntu/Debian) ثبّت أيضًا الأدوات الثنائية:
#   sudo apt-get install tesseract-ocr tesseract-ocr-ara poppler-utils
# tesseract-ocr-ara اختيارية، لكنها ضرورية لاستيراد ملفات أسئلة عربية (راجع OCR_LANGS أدناه)
pip install groq                                     # اختيارية، لتفعيل الربط الذكي الفعلي (مجانًا عبر Groq) بين الأسئلة والشرح
# أو، كبديل: pip install anthropic                   # لتفعيل الربط الذكي عبر Claude بدل Groq

python manage.py migrate
python manage.py createsuperuser --phone 01000000000   # سيطلب الاسم وكلمة المرور، الدور owner تلقائيًا عبر create_superuser
python manage.py runserver
```

افتح المتصفح على http://127.0.0.1:8000

## بنية المشروع
- `accounts` — المستخدم المخصص (دخول بالهاتف)، الصفحة الرئيسية العامة، التسجيل/الدخول، إعدادات المنصة
- `learning` — الدورات/الوحدات/الدروس/الأقسام/الاختبارات/الأسئلة/التقدّم/الأخطاء + محرك الربط الذكي بالشرح (`learning/ai.py`)
- `billing` — الاشتراكات والمدفوعات (تفعيل يدوي بعد رفع إيصال)
- `comms` — الإشعارات والإعلانات والرسائل وتذاكر الدعم
- `examimport` — استيراد الاختبارات من ملفات PDF/صور (استخراج، تحليل، مراجعة المدرّس)
- `student` / `teacher` / `owner` — لوحات التحكم الثلاث (كل واحدة مبنية من الصفر بروابطها الخاصة)

## استيراد الاختبارات والربط الذكي بالشرح (الميزتان الجديدتان)

### 1) استيراد الاختبارات من ملف (PDF/صور)
من صفحة أي اختبار في لوحة المدرّس: **الأسئلة → 📥 استيراد من ملف (PDF/صور)**.
يرفع المدرّس ملف PDF (نصيًا أو ممسوحًا ضوئيًا) أو صورة/مجموعة صور، فيقوم النظام (`examimport`) بـ:
استخراج النص (مباشرة أو عبر OCR) ← تحديد بداية كل سؤال ← تحديد اختياراته ← تحديد إجابته الصحيحة (من علامة
داخل الملف أو من "Answer Key" في نهايته) ← عرض كل سؤال بجانب نصه الأصلي للمراجعة، مع درجة ثقة وحالة
(جاهز / يحتاج مراجعة / تعذّر تحليله). يمكن للمدرّس تعديل أي سؤال أو استبعاده، ثم يضغط **"إضافة الأسئلة
للاختبار"** فتُنشأ الأسئلة الحقيقية فعليًا — لا يُضاف شيء تلقائيًا دون مراجعته.

هذا محلّل قائم على قواعد نصية يغطي الصيغ الشائعة (ترقيم بالأرقام، اختيارات A/B/C/D أو (أ)(ب)(ج)(د)، علامة
✓ أو Answer Key)، وليس نموذج فهم مستندات كامل؛ أي حالة غامضة تُعرض للمراجعة اليدوية بدل تخمينها.

### 2) الربط الذكي بين الأسئلة وأقسام الشرح
من صفحة أي اختبار: **🧠 الربط الذكي بالشرح**، ثم **"تشغيل الربط الذكي"**. يقرأ النظام (`learning/ai.py`)
كل أسئلة الاختبار مع أقسام شرح دروسه المرتبطة (نفس نموذج `LessonSection` الموجود أصلًا)، ويقترح لكل سؤال
أنسب قسم شرح مع درجة ثقة، بانتظار اعتماد المدرّس أو تعديله. عند الاعتماد يُكتب القسم مباشرة في حقل
`Question.section` الأصلي، فتعمل به تلقائيًا كل الأماكن التي تعتمد عليه أصلًا (زر "راجع هذا الجزء من
الدرس" وسؤال "حل سؤالًا مشابهًا" في صفحة نتيجة الطالب) دون أي تعديل إضافي — وأضفنا لصفحة النتيجة أيضًا
عرضًا مباشرًا لمحتوى القسم المرتبط.

يعمل الربط بثلاث طرق مرتّبة حسب الأولوية:
1. عبر **Groq** (مجانًا) إن ضُبط متغيّر البيئة `GROQ_API_KEY` — فهم دلالي حقيقي بنموذج `openai/gpt-oss-120b` افتراضيًا.
2. وإلا عبر **Claude** إن ضُبط `ANTHROPIC_API_KEY`.
3. وإلا تلقائيًا بخوارزمية تقريبية محلية (تشابه الكلمات المفتاحية)، حتى تستمر الميزة بالعمل دون اتصال بالإنترنت
   — مع توضيح ذلك للمدرّس في سبب كل اقتراح.

⚠️ ملحوظة عن الخطة المجانية في Groq: الحدود منخفضة جدًا لكل نموذج (مثلًا `openai/gpt-oss-120b`: 30 طلبًا/دقيقة،
1000 طلب/يوم، 8000 توكن/دقيقة). النظام يترك فاصلًا زمنيًا صغيرًا بين طلبات كل سؤال ليتجنّب تجاوز الحد (خطأ 429)،
ولو حدث تجاوز رغم ذلك يتراجع تلقائيًا لخوارزمية المطابقة التقريبية لهذا السؤال بدل التوقف بالكامل. لذلك اختبارات
كبيرة العدد (عشرات الأسئلة) قد تستغرق وقتًا أطول عند تشغيل الربط الذكي.

### متغيرات بيئة اختيارية
- `MAX_IMPORT_FILE_MB` (افتراضي 15) — الحد الأقصى لحجم كل ملف مستورَد
- `OCR_LANGS` (افتراضي `eng`) — لغات Tesseract؛ اضبطها إلى `eng+ara` بعد تثبيت حزمة اللغة العربية
- `GROQ_API_KEY` — لتفعيل الربط الذكي الفعلي عبر Groq (مجانًا) بدل الخوارزمية التقريبية، وله الأولوية إن وُجد
- `ANTHROPIC_API_KEY` — بديل احتياطي: يُستخدم فقط إن لم يوجد `GROQ_API_KEY`
- `AI_MAPPING_MODEL` (افتراضي `openai/gpt-oss-120b` لأنه مناسب لـ Groq؛ غيّره لموديل Claude لو استخدمت `ANTHROPIC_API_KEY` بدلًا منه)

## نقاط مهمة
- قاعدة البيانات: SQLite (الافتراضية)
- الدخول برقم الهاتف وكلمة المرور (لا يوجد اسم مستخدم منفصل)
- الاشتراك شهري ثابت (30 يومًا)، والدفع يدوي: الطالب يرفع صورة إيصال التحويل، ويراجعه المالك من `/owner/payments/` ثم يفعّل الاشتراك
- ملفات الفيديو والملفات وإيصالات الدفع تُخزَّن في `private_media/` ولا تُخدم إلا عبر Views تتحقق من الصلاحية (لا روابط مباشرة)
- لإنشاء مدرّس جديد: من لوحة المالك → المدرّسون → إضافة مدرّس (يُولَّد له Teacher ID تلقائيًا)
- الطالب ينضم لمدرّس بإدخال Teacher ID من صفحة "المدرّسون" داخل لوحته
